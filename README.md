## Проект: Определение популярных точек для установки банкоматов (ML)

**Кратко о проекте:**  
На основе данных о банкоматах и объектах инфраструктуры Москвы построена ML-модель для прогнозирования перспективных точек установки новых устройств.  
Лучшие результаты показал CatBoost (Recall = 0.75, ROC-AUC = 0.87), ключевые факторы — насыщенность инфраструктурой.

---

**Цель:**  
Провести анализ геопространственных данных и построить модель для оценки перспективности размещения банкоматов.

**Статус:** Проект завершен  

### Этапы проекта

[x] **Сбор и подготовка данных**
- Получение исходных геоданных из открытых источников
- Унификация системы координат
- Очистка от невалидных записей

[x] **Построение сетки кандидатов**
- Создание регулярной сетки точек в пределах МКАД
- Фильтрация по административным границам

[x] **Формирование признаков**
- Подсчёт POI (кафе, магазины, аптеки, остановки)
- Расчёт характеристик в радиусах 300/500 м
- Формирование суммарных индексов насыщенности

[x] **Визуализация и анализ распределения**
- Карты плотности и тепловые карты
- Анализ различий между точками с банкоматами и без
- Определение ключевых переменных

[x] **Формирование итогового датасета**
- Итоговый объём: 12 585 точек × 12 признаков
- Баланс классов: 14,2% / 85,8%
- Финализация набора для моделирования

[x] **Обучение моделей (ML)**
- Тестирование Logistic Regression, Decision Tree, Random Forest, CatBoost
- Сравнение по Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC
- Оптимизация и интерпретация результатов

### Итоги
- **CatBoost** — лучший Recall (0.75) и ROC-AUC (0.87), оптимален для поиска перспективных точек
- **Random Forest** — максимальная Precision (0.61) и Accuracy (0.88), подходит для точных рекомендаций
- **Logistic Regression** — интерпретируемый baseline (ROC-AUC 0.86)
- **Decision Tree** — простая интерпретация, Recall высокий (0.79), но Precision низкий (0.35)
- **Ключевые факторы:** насыщенность инфраструктурой (poi_sum_300/500), близость к аптекам, магазинам и остановкам
- **Практическая ценность:** модель даёт инструмент для оценки перспективности точек с возможностью регулирования баланса Precision/Recall
