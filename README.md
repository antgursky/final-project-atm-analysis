# Проект: Определение популярных точек для установки банкоматов (ML)

**Цель:**  
Анализ геоданных Москвы с использованием OSM и открытых источников. Построение модели, которая оценивает перспективность размещения банкоматов.  

**Статус:** в работе  
**Текущий этап:** подготовка финального датасета (объединение признаков, формирование целевой переменной).  

---

## Этапы проекта

- [x] **Сбор и подготовка данных**  
  • Загрузка сырых геоданных (ATM, POI)  
  • Объединение и приведение к единой проекции  
  • Очистка дубликатов и лишних колонок  

- [x] **Построение сетки кандидатов**  
  • Формирование точек внутри границ Москвы  
  • Фильтрация по полигону города  

- [x] **Формирование признаков**  
  • Количество кафе, аптек, магазинов, остановок, банкоматов  
  • Радиусы: 300 м и 500 м  

- [x] **Формирование итогового датасета**  
  • Признаки + целевая переменная `target`  
  • Сохранение в CSV и GeoJSON  

- [ ] **Моделирование (ML)**  
  • Logistic Regression, Decision Tree  
  • Random Forest, Gradient Boosting (CatBoost)  
  • Метрики: Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC  
  • Выбор лучшей модели и интерпретация признаков  
  • Визуализация предсказаний на карте  

---

## Структура проекта

- `data/raw/` — необработанные данные
