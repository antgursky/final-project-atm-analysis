## Проект: Определение популярных точек для установки банкоматов (ML)

**Цель:**  
Анализ геоданных Москвы с использованием OSM и открытых источников. Построение модели, которая оценивает перспективность размещения банкоматов.  

**Статус:** в работе  
**Текущий этап:** Обучение модели.  


### Этапы проекта

- [x] **Сбор и подготовка данных**  
  • Загрузка геоданных (банкоматы, POI, границы Москвы, метро)  
  • Приведение к единой проекции (CRS)  
  • Очистка дубликатов и пустых геометрий  

- [x] **Построение сетки кандидатов**  
  • Формирование регулярной сетки точек внутри МКАД  
  • Фильтрация по границам города  

- [x] **Формирование признаков**  
  • Подсчёт объектов инфраструктуры (кафе, магазины, аптеки, остановки, банкоматы)  
  • Радиусы: 300 м и 500 м  

- [x] **Визуализация распределения банкоматов**  
  • Тепловая карта по сетке кандидатов  
  • Карта плотности по районам  
  • Топ-5 и анти-топ-5 районов  
  • Примеры по станциям метро  
  • Итоги и ключевые переменные  

- [x] **Формирование итогового датасета**  
  • Объединение признаков и целевой переменной `target`  
  • Проверка структуры и баланса классов  
  • Итоговый размер: **12 585 точек × 24 признака**  
  • Баланс классов: **14,2% положительных и 85,8% отрицательных**  

- [ ] **Обучение модели (ML)**  
  • Построение и обучение базовых и ансамблевых моделей:  
    - Logistic Regression  
    - Decision Tree  
    - Random Forest  
    - Gradient Boosting (CatBoost)  
 


### Структура проекта

- `data/raw/` — необработанные данные  
- `data/processed/` — очищенные датасеты  
- `notebooks/` — Jupyter-ноутбуки (основной: `01_data_collection.ipynb`)
