# Проект: Определение популярных точек для установки банкоматов (ML)

**Цель:**  
Анализ геоданных Москвы с использованием OSM и открытых источников. Построение модели, которая оценивает перспективность размещения банкоматов.  

**Статус:** в работе  
**Текущий этап:** подготовка финального датасета (объединение признаков, формирование целевой переменной).  

---

## План проекта

- [x] **Сбор данных**  
  - [x] OpenStreetMap (банкоматы, точки интереса, транспорт)  
  - [ ] Дополнительные открытые источники  

- [x] **Подготовка и анализ данных (EDA)**  
  - [x] Очистка и нормализация данных  
  - [x] Карты плотности банкоматов и инфраструктуры  
  - [x] Визуализация распределений  

- [ ] **Формирование признаков**  
  - [x] Признаки доступности инфраструктуры (POI: кафе, аптеки, магазины, транспорт)  
  - [x] Признаки конкуренции (банкоматы в радиусе)  
  - [ ] Потенциально — население и транспортные данные  

- [ ] **Machine Learning**  
  - [ ] Подготовка датасета (train/test split)  
  - [ ] Модели: логистическая регрессия, деревья решений и ансамбли  
  - [ ] Сравнение метрик и интерпретация факторов  

- [ ] **Визуализация и выводы**  
  - [ ] Интерактивная карта перспективных точек  
  - [ ] Итоговый отчёт и презентация
