## Проект: Определение популярных точек для установки банкоматов (ML)

**Цель:**  
Провести анализ геопространственных данных и построить модель для оценки перспективности размещения объектов инфраструктуры.

**Статус:** в работе  
**Текущий этап:** Обучение модели.

### Этапы проекта

  [x] **Сбор и подготовка данных**

  - Получение исходных геоданных из открытых источников
  - Унификация системы координат
  - Предобработка данных и очистка от невалидных записей

  [x] **Построение сетки кандидатов**
  - Создание регулярной сетки точек в пределах целевой территории
  - Фильтрация точек по административным границам

  [x] **Формирование признаков**
  - Анализ инфраструктурного окружения для каждой точки
  - Расчет характеристик в различных радиусах

  [x] **Визуализация и анализ распределения**
  - Построение тепловых карт и карт плотности
  - Выявление зон с различной концентрацией объектов
  - Анализ ключевых закономерностей и переменных

  [x] **Формирование итогового датасета**
  - Объединение признаков и целевой переменной
  - Проверка качества и сбалансированности данных
  - Финализация структуры набора данных для моделирования

  [ ] **Обучение модели (ML)**
  - Тестирование различных алгоритмов машинного обучения
  - Сравнение производительности базовых и ансамблевых моделей
  - Оптимизация и валидация результатов

### Структура проекта

- `data/raw/` — исходные данные
- `data/processed/` — обработанные данные
- `notebooks/` — файлы с исследовательским анализом

- **Библиотеки машинного обучения**
- **Инструменты для интерактивного анализа**
